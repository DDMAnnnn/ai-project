# Cardgame

## mathcard

- *This is a rouge-like card game with some basic mathematics*
- *Any gamer is welcomed to play the game*
- *In the game, you will enjoy defeating monster with simple math and strategy*

## User Stories

- *As a user, I want to be able to:
- 1. use cards to battle with enemy
- 2. get reawrd after defeating enemy
- 3. be able to save&load the game

- *During battle I want to be able to:
- 1. see status of me and enemy
- 2. damage enemy
- 3. defend enemy's attack
- 4. cancel an unfinished action
- 5. view my drawing pile, discard pile and deck
- 6. have a tutorial
- 7. draw card from drawing pile to hand
- 8. discard cards to discard pile

- *For reward I want to be able to:
- 1. choose from random cards and add to my deck
- 2. skip the reward
- 3. remove card from my deck

- An example of event log:
- A number card is added to the deck. (if a card with type NUMBER is added.)
